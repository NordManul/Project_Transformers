# Свип lr для nGPT vs GPT — инструкция для Егорчика

Мы вчетвером (Манул, Арсёнок, Аннушка, Егорчик) подбираем learning rate для GPT и nGPT,
чтобы честно сравнить модели. У каждого свой аккаунт Kaggle и две видеокарты T4,
всего 8 видеокарт. Прогоны распределены так, чтобы все закончили примерно одновременно.

**Твои прогоны:** шаг 1 — только GPT: lr 0.003, потом 0.006 на одной видеокарте, 0.012 на другой; шаг 2 — проверка: GPT и nGPT с ПОЛОВИНОЙ лучших lr, сид 42.

---

## Подготовка (один раз)

1. Аккаунт Kaggle с **подтверждённым телефоном**: аватар → Settings → Phone Verification = Verified.
   Без этого не будет GPU и интернета.
2. Скачай ноутбук: открой
   https://github.com/NordManul/Project_Transformers/blob/master/kaggle_sweep.ipynb
   → кнопка **Download raw file** (справа над кодом) → сохранится `kaggle_sweep.ipynb`.
3. На kaggle.com: **Create → New Notebook → File → Import Notebook** → выбери `kaggle_sweep.ipynb`.
4. Переименуй ноутбук (клик по названию сверху) в **`ngpt-sweep-egorchik`**, чтобы Манул его нашёл.

## Шаг 1. Короткий свип (150M токенов) — ~2.4 ч

### 1.1. Первая ячейка с кодом: поставить эти значения
```python
LR = "3e-3"
BUDGET = "150M"
SEED = 42
LRS_GPT = "3e-3,6e-3,1.2e-2"
LRS_NGPT = "none"
```
Остальные строки ячейки не трогай.

### 1.2. Справа, в Session options
- **Accelerator → GPU T4 x2**
- **Internet → On**
- раздел **Input** должен быть **пустым** (если что-то есть — ⊖ убрать)

### 1.3. Запуск
**Save Version → Save & Run All (Commit) → Save.**
Потом в редакторе кнопка **⏻** (выключить интерактивную сессию, чтобы не тратить квоту).
Браузер и компьютер можно закрыть: всё идёт на серверах Kaggle.

### 1.4. Проверка через ~20 минут
Your Work → ноутбук → версия → **Logs**. Должно быть:
```
код: <короткий хэш>            ← у всех четверых должен совпадать
openwebtext: val 10,000,000 + train 900,000,000 токенов ...
План: ... устройства ['0', '1'] ...
[0] gpt_150M_lr0.003: старт ...
[1] gpt_150M_lr0.006: старт ...
(через ~1 ч) [0] gpt_150M_lr0.012: старт ...
```
Если строки «Копирую данные из входа» или «Продолжаю эксперимент» — **остановить** (Active Events → ⋯ → Cancel),
убрать всё из Input и запустить заново.

### 1.5. Когда закончится
Ноутбук → **Share** → **Add collaborators** → `vladimir337` (это Манул) → права **Can view**.
Напиши в чат: «шаг 1 готов».

## Шаг 2. Полный прогон (775M токенов) — ~8.7 ч

Манул пришлёт в чат лучшие lr из шага 1: **X_g** (для GPT) и **X_n** (для nGPT).

### 2.1. Первая ячейка
```python
BUDGET = "775M"
SEED = 42
LRS_GPT = "X_g/2"
LRS_NGPT = "X_n/2"
```
Манул пришлёт готовые числа (например, X_g/2 = 1.5e-3). Зачем: на коротком обучении лучший lr выходит выше, чем на длинном, — твой прогон проверяет, не лучше ли вдвое меньший.

### 2.2. Данные без повторной подготовки (экономит 14 минут)
Справа **Add Input → Your Work → `ngpt-sweep-egorchik`** (свой ноутбук из шага 1).
В логе будет «Копирую данные из входа» — **в шаге 2 это нормально**.
Но строки «Продолжаю эксперимент» быть не должно.

### 2.3. Запуск и проверка
Как в шаге 1: GPU T4 x2, Internet On, **Save & Run All**, ⏻.
В логе: `План: 2 прогонов, устройства ['0', '1']` и две строки `старт` (GPT на [0], nGPT на [1]).

### 2.4. Когда закончится
Share уже настроен (тот же ноутбук). Напиши в чат: «шаг 2 готов».

## Если что-то пошло не так
- **Ошибка в логе** — пришли последние ~30 строк Logs в чат.
- **CUDA out of memory** — не должно быть (у nGPT ~8.4 ГБ из 15). Если всё же есть — напиши.
- **Квота**: шаг 1 + шаг 2 ≈ ~11 ч из ~30 ч в неделю.
